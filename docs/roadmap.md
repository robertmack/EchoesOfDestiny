# Development Roadmap

## Version 0.0.1

Goal: prove that the core loop is fun.

- one small map
- one character
- gather sticks, stones, grass, and wild grain
- craft a crude hoe
- prepare soil and plant wheat
- tend the field and harvest wheat
- cook wheat and eat
- sleep
- record and replay a routine

## Version 0.1

Goal: add the first meaningful layer of memory.

- a simple routine memory slot
- partial replay of yesterday's actions
- basic achievements such as first tool and first harvest
- visible time progression and a morning choice

## Version 0.2

Goal: introduce the first echo-like persistence.

- some work begins to persist between days
- fields or tools become partially remembered
- the world feels less like a reset and more like a place that remembers
