# Design Journal

## 2026-07-19

- The core idea is that the world tends toward forgetting, while awakened characters preserve memory.
- The player inhabits one character for a day and teaches that character how to live through routines.
- Repeated effort should create echoes of permanence rather than simply grant power.
- The first prototype should focus on one character, one small homestead, and one clear day loop.
- The game should feel like reclaiming time and making a place livable again, not like grinding for stats.
